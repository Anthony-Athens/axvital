## 15. Display-label/unit contract changes

Added an independent presentation contract:

```ts
display?: {
  version: 1;
  outcomeLabel: string;
  unit: string | null;
  scaleLabel: string | null;
} | null
```

Projection uses the retained primary outcome definition, checking its key/version/unit/scale against the supported registry contract. The label comes from the retained definition, not a mutable current label. Ratio units come from that verified definition. Rating/ordinal scale labels describe the authoritative unit contract, not guesses from question text. No source IDs or full frozen definitions are exposed. Missing/mismatched metadata yields generic Outcome with no unit. Older DTOs without display metadata remain supported; unknown display versions fall back safely.

Analysis contract/policy versions, capture format, evidence text, digest, and replay calculations are unchanged. This additive display version does not reinterpret existing analysis revisions. Intervention and period labels remain generic rather than exposing unnecessary frozen configuration.
